# 批量千川去重工具 — 批量矩阵生产，喂饱千川计划

千川计划的素材消耗是"按条计算"的：计划越多、跑量越大，需要的新素材就越多。
单条去重根本供不上，**批量千川去重**才是正确姿势——一次导入几十上百条素材，自动批量产出几十上百条去重成片。

## 核心功能

- ✅ **批量导入批量产出**：一次导入 N 条素材，自动批量去重产出 M 条成片，填多少出多少
- ✅ **选品中心批量生产**：按佣金、素材数筛选商品，全表商品一键"批量下载 → 批量混剪"全自动跑完
- ✅ **批量任务调度**：任务中心统一队列，进度实时透明，失败自动重试，批量任务不崩溃
- ✅ **成品条条不同**：每条成片随机组合去重手法，不撞车、不模板化
- ✅ **批量消字幕**：原素材字幕/水印批量无痕消除
- ✅ **批量横竖屏转换**：横屏素材自动转竖屏，智能跟随主体裁切

## 批量生产链路

```
选品筛选 → 素材批量下载 → 批量去重/混剪 → 任务中心调度 → 成品库归集 → 批量投放
```

全程自动化，人工只负责选品和投放。
